# Aggie Table Tennis

Open `index.html` for a local preview. The site uses plain HTML and CSS and needs no build command.

## Publish on GitHub Pages

Create an empty public GitHub repository under the club account. Upload the contents of this folder to the repository root, including `assets/` and `.nojekyll`, or push the local `main` branch. In the repository, open **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, choose **main** and **/(root)**, then save. GitHub shows the published URL in Pages settings after deployment.

## Update the site

- Add announcement cards or change meeting information in `index.html`. Update the page description if the practice schedule changes.
- Replace the GroupMe email fallback with the club’s invite URL when available.
- Replace the GoFundMe placeholder with a link once the fundraiser goes live.
- Save the official PNG emblem as `assets/aggie-logo.png` if that file is absent. The header uses a simple fallback mark until then.
